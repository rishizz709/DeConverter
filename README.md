## 🚀 What is DeConverter?

Forget switching between multiple websites and tools just to convert a file.

**DeConverter** brings file conversion and productivity workflows together in one desktop experience. Its interactive radial menu presents available actions based on the file you select and the capabilities available on your system.

<blockquote>
Select a file. Discover what you can do. Get it done.
</blockquote>

## 📥 Getting Started

### Windows

**Installer**

1. Download `DeConverter_Setup.exe`.
2. Run the installer.
3. Follow the setup instructions.

**Portable**

1. Download `DeConverter-Portable.zip`.
2. Extract the archive.
3. Run `DeConverter.exe`.

Keep all extracted portable files together.
