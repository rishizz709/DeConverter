# DeConverter

### One File. Every Possibility.

**DeConverter** is an all-in-one Windows desktop toolkit for file conversion and productivity. Convert, manage and process files through one intuitive application built around an interactive radial menu.

## Features

- **Radial Menu** — Interactive animated menu for file operations.
- **File Conversion** — Documents, PDFs, images, audio, video, archives and more.
- **Smart Detection** — Detects file types and available conversion capabilities.
- **Batch Processing** — Process multiple files with progress, retry and queue controls.
- **PDF Tools** — PDF merging, splitting, rotation, compression and supported conversions.
- **File Management** — History, favorites, presets and naming rules.
- **Offline Tools** — Local productivity utilities where supported.
- **Windows Integration** — Designed for Explorer context menu and other workflows.
- **Plugin Support** — Extensible functionality.

## Getting Started

**Installer:** Download and run `DeConverter_Setup.exe`.

**Portable:** Extract `DeConverter-Portable.zip` and run `DeConverter.exe`. Keep the extracted files together.
